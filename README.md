# Requisitos previos
- NodeJS ^20.10
- NPM ^10.2.0
- GIT ^2.51.0

# Instalación
- Ejecute el script `instalar-entorno-desarrollo`
- Instale TODAS las extensiones recomendadas por VSC para este proyecto
- Ejecute el script `iniciar-sesion`
- Ejecute el script `descargar-tema`
- Ejecute el script `previsualizar-tema`
- Ya puedes trabajar con el codigo

# Tareas terminadas
- Sube tus cambios a GIT. A la rama develop
- Si quieres publicar estos cambios a la tienda online tambien, ejecuta  `publicar-tema`
