# Requisitos previos
- NodeJS ^20.10
- NPM ^10.2.0
- GIT ^2.51.0

# Instalación

- Instale TODAS las extensiones recomendadas por VSC para este proyecto
- Ejecute el comando NPM `npm run instalar-entorno-desarrollo`
- Ejecute el comando NPM `npm run iniciar-sesion`
- Ejecute el comando NPM `npm run descargar-tema`
- Ejecute el comando NPM `npm run previsualizar-tema`
- Ya puedes trabajar con el código

# Tareas terminadas
- Sube tus cambios a GIT. A la rama develop
- Si quieres publicar estos cambios a la tienda online también, ejecuta el comando NPM  `npm run publicar-tema`
